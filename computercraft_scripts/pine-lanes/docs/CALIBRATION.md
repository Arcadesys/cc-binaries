# Physics calibration

Pine Lanes runs the furball-simulator bowling kernel (`src/sports/bowling/sim/{trajectory,pinAction,shot}.ts`), ported line for line to `lib/pindeck.lua`. Tuning lives in furball; this game does not re-tune it. All constants keep furball's values and names (`BOWLING_*` → `deck.*`).

Scene units: X across the lane (+ right), Z along it. Release at z = 5.7, head pin at z = −5, rows 0.8 apart with 1.1 between neighbours, pit at z = −9. The ball (radius 0.3055) travels the lane in 1650 ms. Its path is `releaseX + angle·4.8·p + spin·3.4·hook(p)²`, with hook starting at 35% of the lane; the first gutter crossing (edge 2.45) is found by bisection and locks the ball out of the deck. The pin deck integrates at 120 Hz: pins are capsules that topple above an impulse of 0.65, fallen pins carry momentum into neighbours, and the deck must settle within 5 s. A seeded mulberry32 draw sets each pin's bounce (0.28–0.38) for the full rack, so removing a pin never changes another's material.

Pine axes: `X = 5.7 − z`, `Z = x` (see `lib/lane.lua`). Furball poses carry the capsule centre; the adapter converts them to Pine's foot/fall-direction/tilt poses for drawing.

Reference fixtures (seeded, fresh rack unless noted):

| Shot | Controls (position, angle, spin, power) | Result |
|---|---|---|
| Pocket strike | −32, +10, 0, 100 | 10 pins for every seed tried (40/40 in furball, 6/6 in `tests/physics.lua`) |
| Straight down the middle | 0, 0, 0, 100 | Never strikes: the head-on hit leaves corner pins |
| Hooked leave | +30, −6, +18, 72 (seed 9) | Partial rack; the spare ball only ever topples survivors |
| Gutter | +100, +30, +100, 100 | Locks out before the rack, 0 pins |
| Short | 0, 0, 0, 10 | Stops before the head pin, 0 pins |

`tests/furball.lua` replays 66 shots generated by the TypeScript kernel (including partial racks) and requires identical pins, contact events, durations and final poses.
