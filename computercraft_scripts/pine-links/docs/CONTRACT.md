> **Historical.** This describes the original Pebble Beach hole 7 prototype. Pine Links now runs furball-simulator's Marovitz-inspired Hole 3 and golf kernel; see `README.md`.

# Milestones 0–2 working contract

Route: coordinator integration plus three bounded Luna workers, explicitly requested by user. Medium effort for physics, source geometry, and renderer/input; interface fixed first because these components depend on one another. No other holes, persistence, networking or publishing.

Coordinates: yards; x/z ground, y up; tee x=0,z=0; cup x=107,z=0; aim radians, 0 points +x. Lua require paths `lib.course`, `lib.physics`, `lib.rules`, `lib.render`, `lib.input`, `lib.ui` from pine-links cwd. No renderer dependencies in course/physics/rules.

Course: `course.hole` metadata and geometry; `course.sample(x,z)` returns nil outside land, otherwise `{height, nx, ny, nz, material}`. `hole.triangles` array `{a={x,y,z},b={x,y,z},c={x,y,z},material=...}` is the sole collision/render source. `hole.tee`, `hole.cup` positions; cup radius=0.6 yards (arcade), captureSpeed=2.0 yd/s. `hole.waterLevel`, `hole.bounds={minX,maxX,minZ,maxZ}`. Course worker owns course.lua, hole data, geometry tests, source/reference docs and top-down preview tool.

Physics: `physics.clubs` array `{id,name,carry}` wedge,putter,test; `physics.begin(course, shot)` returns simulation; `physics.advance(sim, steps)` advances at fixed 1/60, returns boolean done. Shot `{start={x,y,z},club='wedge',aim=0,power=0..1,wind={x=0,z=0}}`. Sim exposes `trajectory` positions `{x,y,z,t}`, `result` when done `{position={x,y,z},outcome='rest'|'holed'|'water'|'ob'|'error',message?,surface?,duration}`, each batch <=120 steps; max duration and finite checks. `physics.simulate(course,shot)` helper for tests. Rules: `new(tee)` returns `{ball,strokes=0,penalties=0,complete=false,lastShotId=0}`; `apply(state,shotId,result,preShot)` idempotently counts stroke + hazard penalty, resets hazard to preShot, no count on error; `scoreName(strokes,par)`. Physics worker owns physics.lua,rules.lua and focused tests plus tests/run.lua.

Renderer/UI: render.new(target,course) -> renderer; renderer:draw(view); renderer:resize(); renderer:close(). view `{ball,aim,power,club,strokes,penalties,phase,message,view='tee'|'map',fine=false,lastInput,fps}`; phase 'TITLE'|'AIM'|'SIMULATE'|'SHOT_PLAYBACK'|'SCORECARD'|'HELP'|'PAUSED'|'DIAGNOSTIC'. Use Pine3D for tee 3D, shared mesh, projected ball/shadow/flag, map toggle. `ui.layout(w,h,phase)` returns array of `{id,label,x,y,w,h}` controls. `input.action(event,buttons,monitorName)` returns action or nil; actions start,aim_left,aim_right,power_up,power_down,club_prev,club_next,swing,view,fine,help,pause,restart,quit,skip. Keys arrows,Q/E,Space,Tab,F,H,P,R,Escape; monitor tap rectangles and terminal mouse separate, foreign monitor ignored. Renderer worker owns vendor files/license lock, render.lua,ui.lua,input.lua and input tests. No browser UI work required.

Coordinator owns golf.lua, lib/app.lua, diagnostic.lua, integration tests, README and validation receipts. Workers send changed facts/API deviations immediately. Source spec is PLAN.md; do not read unrelated private context.

Completion evidence: deterministic core tests, actual installed CraftOS-PC terminal and emulated Advanced Monitor play/recovery checks, rendered readability review and saved captures/logs. Minecraft/ATM10 compatibility remains explicitly pending unless actually run there.
